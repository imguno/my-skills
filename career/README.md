## 다운로드

저장소 루트에서:

```sh
npm run download -- career
```

또는 이 폴더에서:

```sh
npm run download
```

현재 실행 폴더의 `downloads/`에 저장한다. 다른 위치는 `npm run download -- --dest "원하는/경로"`로 지정한다.
